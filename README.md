# PrivyTools

Privacy-first file utilities that run entirely in your browser.

No uploads. No servers. No accounts.

## Live Site

Once GitHub Pages is enabled, the site will be available at:
https://Basu-D.github.io/privytools/

## Features

- Merge PDFs
- Rotate PDF pages
- Image compress / resize / convert
- Images to PDF
- Base64 encode / decode

All processing happens client-side using pdf-lib and the Canvas API.
